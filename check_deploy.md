# Checklist Deploy Vercel

## Passos para verificar:

1. **Acesse o Vercel Dashboard**
   - https://vercel.com
   - Selecione seu projeto "site-myfirstcocktail"

2. **Vá em Deployments**
   - Deve estar em "Building" ou "Ready"
   - Se estiver "Ready" = já foi feito

3. **Se ainda estiver carregando**
   - Espera terminar (2-5 min)
   - Recarrega a página em 1 minuto

4. **Se continuar 404**
   - Força rebuild: 
     - Clique nos 3 pontinhos do deploy
     - "Redeploy"
